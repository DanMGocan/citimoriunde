## Decisions

- Application workspace is `/root/biblioteca`; protected `/root/.git`, `.env`, credentials, SSH settings and unrelated services are preserved.
- Current preview brand is `APP_NAME=Biblioteca Diasporenilor`. User domain `citimoriunde.eu` appears in setup instructions; runtime URL remains configurable.
- Next 16.4.0, React 19.3.0, Better Auth 1.7.7, Drizzle 0.45.2 and `pg` 8.16.3 are installed with a real `package-lock.json`; clean `npm ci` passes. Sharp is patched to **0.35.5**; the latest dependency audit reports **0 vulnerabilities**. Installed compatibility and outstanding container/provider checks are documented in `docs/DEPENDENCY_COMPATIBILITY.md`.
- Native execution uses **Node 22.22.1** and **PostgreSQL 18.6**; PostgreSQL is bound to loopback. The configured Docker image remains Node 24.21.0, with container execution still pending. SQL migrations are authoritative for database constraints; Drizzle supports typed public projections and domain writes use direct parameterized transactions.
- Native app and worker run unprivileged from `/opt/biblioteca`, using protected systemd `LoadCredential` to read the unchanged workspace `.env`. The app listens at `127.0.0.1:3000`; the separate native Caddy proxy serves `https://citimoriunde.eu`. All three services are enabled and active. Native web/worker/proxy memory caps are 1 GiB/384 MiB/192 MiB and CPU quotas are 100%/25%/15%; these limits do not establish production capacity.
- Modular monolith, one PostgreSQL-backed worker, processing concurrency 1, no Redis/microservices/Elasticsearch. The production design uses a private database, persistent photos and non-root web/worker processes.
